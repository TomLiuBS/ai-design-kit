# 実測スクリプト

**実測スクリプト（Script A〜D）は、[design-system-measure](../../design-system-measure/scripts/measure-scripts.md) スキルに移した。ここにはスクリプトを置かない（二重管理するとスクリプトごとに数え方がずれるため）。**

- 本スキルの実測項目（A1・C4・D1・E6、F1の記載率、A5・B1・B2・C1の違反候補率、A4・B5・E1・E2（Script E））は、`design-system-measure` で測った値を証拠として引用する。引用時は、測定日・対象・起点node-id・本体かブランチかを併記する。
- 測定結果がない場合は、`design-system-measure` の手順に従って測る。本スキルの中で独自のスクリプトを書いたり、手で数えたりしない。
- 走査範囲（起点・深さ・COMPONENT内部・INSTANCE内部・非表示レイヤー）の固定規定も、移行先に従う。
