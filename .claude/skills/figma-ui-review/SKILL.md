# UIレビュー

## 簡単な使い方

```
デザインのレビューをして
https://www.figma.com/design/<fileKey>/...
```

または:
```
デザインのレビューをして
[スクリーンショット]
```

---

## ⚠️ 実行ルール（必須）

以下のルールをすべて守ること。省略・要約・スキップは禁止。

1. **全項目を必ず個別評価する**（画像の場合はPart 1: 18項目、Figma URLの場合はPart 1 + Part 2: 28項目）
2. **各項目にスコア（1〜5 または N/A）を必ず付与する**
3. **スコア根拠を具体的に記述する**（「余白が不統一」× → 「カード間余白が12px・20px・24pxで混在」○）
4. **セクション5「詳細評価」はスコア3.5点以下かつN/A以外の項目のみ出力する**
5. **レポートはドキュメントとして作成する**

---

## 概要

**機能:**
- 画像ベースレビュー: 視覚・インタラクションデザインをカバーする18項目
- Figmaデータレビュー: コンポーネント構造とデザインシステム準拠を含む28項目
- 一括レビュー: 複数画面を一緒に評価し、一貫性をチェック
- 詳細レポート: 項目ごとのスコア（1〜5またはN/A）と具体的なフィードバック・改善提案

---

## 評価方式

**5段階評価 + N/A:**
- **5点**: すべてのチェック項目を満たす（100%）
- **4点**: チェック項目の80%以上を満たす
- **3点**: チェック項目の60%以上を満たす
- **2点**: チェック項目の40%以上を満たす
- **1点**: チェック項目の40%未満
- **N/A**: 評価不能項目が多く、判定できない（画像キャプチャの場合）

## レビューワークフロー

1. **単一画面の画像** → 画像レビュープロセス（Part 1: 18項目）
2. **Figma URL** → Figmaレビュープロセス（Part 1 + Part 2: 28項目）
3. **複数画面** → 一括レビュープロセス

# Part 1: 画像キャプチャで評価可能な項目（18項目）

## 1. 空間デザイン

### 1.1 整列（5項目）
- [ ] すべての主要要素の左端または右端が揃っている
- [ ] テキストと要素が左揃え、右揃え、中央揃えのいずれか1つに統一されている
- [ ] 異なる整列方法が意図なく混在していない
- [ ] 要素の端が視覚的に同一の垂直線または水平線上に配置されている
- [ ] 同種要素の端が仮想の垂直線または水平線から2要素以上外れていない

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 1.2 余白の一貫性（5項目）
- [ ] 同じ種類の要素間の余白が3種類以上に見えない
- [ ] セクション内の余白がセクション間余白の半分以下に見える（近接の原則）
- [ ] 同種要素間の余白が2種類を超えない
- [ ] セクション間の余白がセクション内の余白より大きい（2倍以上）
- [ ] 要素同士が接触・重なっている箇所がない

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 1.3 レスポンシブ対応（4項目）
- [ ] モバイル（320px〜767px）のデザインが存在する
- [ ] タブレット（768px〜1023px）またはデスクトップ（1024px〜）のデザインが存在する
- [ ] 縦向きと横向きの両方のデザインが存在する
- [ ] 各画面サイズでコンテンツが画面内に収まっている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

## 2. 視覚デザイン

### 2.1 色の使い方（5項目）
- [ ] 白背景に白テキスト、黒背景に黒テキスト等の同色・同明度の組み合わせがない（WCAG AA 1.4.3 近似）
- [ ] 薄い灰色テキストが本文に使用されていない（WCAG AA 1.4.3 近似）
- [ ] 白背景に黄・薄黄系テキスト、黒背景に濃紺・暗緑系テキストがない（WCAG AA 1.4.3 近似）
- [ ] 色だけで情報を伝えていない（色+アイコン、色+テキストで補完）（WCAG A 1.4.1）
- [ ] 重要な要素が色、サイズ、または太さで他の要素と区別されている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 2.2 タイポグラフィと視覚的階層（6項目）
- [ ] 最大の見出し（H1相当）は1ページに1つのみである
- [ ] 見出しのサイズがH1 > H2 > H3の順序で小さくなっている
- [ ] 見出しが本文テキストより大きい、または太字である
- [ ] 最重要情報が画面上部1/3以内に配置されている
- [ ] テキスト行同士が重なっておらず、各行が視覚的に独立している
- [ ] 1行のテキスト長が画面幅の80%以下である

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

## 3. 一貫性

### 3.1 デザインパターンの統一（5項目）
- [ ] 同じ種類のボタン（Primary、Secondary等）が画面間で同じ色・形状である
- [ ] 同じ機能を持つ要素が画面間で同じアイコン・色である
- [ ] カード、リスト等のコンポーネントが画面間で同じレイアウト・スタイルである
- [ ] ヘッダー、フッター、ナビゲーションのレイアウトが画面間で統一されている
- [ ] 見出し・本文・補助テキストの3種類を超えるフォントサイズが画面内に存在しない

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 3.2 業界標準への準拠（5項目）
- [ ] ロゴまたはサイト名が左上に配置されている（Web/デスクトップの場合）
- [ ] 検索機能が虫眼鏡アイコンで表現されている
- [ ] ハンバーガーメニュー（モバイル）が右上または左上に配置されている
- [ ] 主要なアクション（保存、送信等）が右側または下部に配置されている
- [ ] プラットフォーム標準（iOS、Android、Web）のナビゲーションパターンに従っている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 3.3 コンポーネントの視覚的統一（4項目）
- [ ] ボタンの角丸が統一されている
- [ ] カードやボックスのシャドウ（影）が統一されている
- [ ] アイコンのスタイルが統一されている
- [ ] フォームの入力欄（テキストボックス）のスタイルが統一されている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

## 4. 情報設計

### 4.1 情報量（7項目）
- [ ] メニューまたはドロップダウンの選択肢が7個以下である
- [ ] 1画面の主要な情報グループ（セクション）が7個以下である
- [ ] 長い数字が区切られている（電話番号をハイフンで区切る等）
- [ ] 複雑な選択が段階的に分割されている
- [ ] 1つのカード・リストアイテム内に表示されるバッジ・タグ・ラベルが3種類以下である
- [ ] 1画面内で同時に使用されている強調色（アクセントカラー）が3種類以下である
- [ ] 同種コンテンツが複数のセクションに分かれており、各セクションが単一の目的で構成されている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 4.2 言葉のわかりやすさ（4項目）
- [ ] アイコンのみの要素にラベル（テキスト）またはツールチップテキストがある
- [ ] 専門用語が使用されていない、または専門用語に説明が付いている
- [ ] ボタンのラベルが動詞で始まっている（例:「保存する」「送信する」「削除する」）
- [ ] エラーメッセージが「エラーコード: 500」ではなく、人間が理解できる説明である

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 4.3 ナビゲーション構造（4項目）
- [ ] グローバルナビゲーション（ヘッダーメニュー等）が存在する
- [ ] 現在位置を示す要素（パンくずリスト、ハイライトされたメニュー項目等）が存在する
- [ ] 主要な機能へのアクセスが3クリック以内で可能な構造である
- [ ] 各画面に「戻る」手段（戻るボタン、閉じるボタン等）が存在する

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

- [ ] フォーカス状態が通常状態と視覚的に区別されている
- [ ] フォーカスインジケーターが他の要素と重ならず、明確に見える

# Part 2: Figmaデータでのみ評価可能な項目（10項目）

**重要:** このセクションはFigmaデータが必要です。画像キャプチャのみの場合、すべて「N/A」となります。

## 7. 定量的品質

### 7.1 グリッドシステムの定量評価（5項目）
- [ ] グリッドシステム（8pt grid、12カラム、または16カラム）が定義されている
- [ ] 主要な要素の80%以上がグリッドラインから±2px以内に配置されている
- [ ] ガター（列間の溝）の幅が統一されている
- [ ] レスポンシブブレークポイントでグリッドの変更ルールが定義されている
- [ ] グリッドからの逸脱が意図的である

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 7.2 余白サイズの定量評価（5項目）
- [ ] 余白の90%以上が8の倍数（8px, 16px, 24px, 32px等）である
- [ ] 関連要素間の余白が8〜16pxの範囲内である
- [ ] 非関連要素（グループ間）の余白が24px以上である
- [ ] 同種要素間の余白が数値的に統一されている（±2px以内）
- [ ] セクション間の余白がセクション内の余白の2倍以上である

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 7.3 コントラスト比の定量評価（5項目）
- [ ] 通常テキスト（14pt未満）と背景のコントラスト比が4.5:1以上（WCAG AA）
- [ ] 大きなテキスト（18pt以上）と背景のコントラスト比が3:1以上（WCAG AA）
- [ ] UIコンポーネント（ボタン、入力欄等）の境界線が3:1以上（WCAG AA）
- [ ] フォーカスインジケーターのコントラスト比が3:1以上
- [ ] すべてのテキストがWCAG AA基準を満たしている

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 7.4 タッチターゲットサイズの定量評価（5項目）
- [ ] すべてのボタンが44×44px以上である（iOS HIG / WCAG AAA準拠）
- [ ] Androidの場合、すべてのボタンが48×48dp以上である（Material Design準拠）
- [ ] リンクのタッチターゲットが44×44px以上である
- [ ] 隣接する要素との間隔が8px以上である
- [ ] Primary Actionボタンが他のボタンより20%以上大きい

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 7.5 テキスト代替の定義確認（4項目）
- [ ] すべての画像、アイコンレイヤーにalt属性相当の説明がある
- [ ] 装飾的な画像には「装飾」または「alt=""」相当の明示がある
- [ ] アイコンのみのボタンにaria-label相当の説明がある
- [ ] グラフや図表に説明テキストレイヤーがある

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

### 7.6 テキスト間隔の定量評価（4項目）
- [ ] 行間（Line Height）がフォントサイズの1.5倍以上（WCAG AA 1.4.12）
- [ ] 段落の間隔がフォントサイズの2倍以上（WCAG AA 1.4.12）
- [ ] 文字間隔（Letter Spacing）がフォントサイズの0.12倍以上（WCAG AA 1.4.12）
- [ ] 単語間隔（Word Spacing）がフォントサイズの0.16倍以上（WCAG AA 1.4.12）

**判定:** [ 1 / 2 / 3 / 4 / 5 / N/A ]

## レポート形式

### 評価スコア基準
- **4.5〜5.0点**: 優秀 - 業界標準に完全準拠
- **4.0〜4.4点**: 良好 - 十分な品質、小さな改善で更に向上
- **3.0〜3.9点**: 標準 - 基本的な品質は確保、改善の余地あり
- **2.0〜2.9点**: 要改善 - 多くの問題があり、優先的に改善が必要
- **1.0〜1.9点**: 不十分 - 致命的な問題があり、即座に対応が必要

### レポート構造
```
1. 概要（評価対象、評価日、総合スコア）
2. 評価結果サマリー（スコア分布、優先対応項目）
3. 改善推奨事項（🔴最優先 / 🟡優先度高 / 🟢優先度中）
4. 総括（強み、改善が必要な領域、次のステップ）
5. 詳細評価（スコア3.5点以下のみ）
6. 評価基準（参考）
```

### スコア表示形式
- 5点: ⭐⭐⭐⭐⭐ **5点**
- 4点: ⭐⭐⭐⭐ **4点**
- 3点: ⭐⭐⭐ **3点**
- 2点: ⭐⭐ **2点**
- 1点: ⭐ **1点**
- N/A: **N/A**

### 判定記号
- ✅ : 基準を満たしている
- ❌ : 基準を満たしていない
- ⚠️ : 一部満たしているが改善推奨

---

## 重要な注意事項

### レポート作成時の必須ルール

1. **具体的な数値を記載する**（「余白が不統一」× → 「カード間の余白が16px、20px、24pxで不統一」○）
2. **測定値を必ず記録する**（コントラスト比: 「3.1:1（基準4.5:1未達）」等）
3. **改善提案は実行可能に**（「コントラストを改善すべき」× → 「背景色を#2196F3から#1976D2に変更し、コントラスト比を4.6:1に向上させてください」○）
4. **優先順位と所要時間を明記**（優先度: 🔴🟡🟢）
5. **評価の客観性を保つ**（個人的な好みではなくチェックリストの基準に基づいて評価する）
