# screen-type-presets.md — 画面タイプ別の状態プリセット

画面骨子を見て、まず以下のどのタイプに当たるか分類する。複数タイプの複合画面もある（例: 一覧＋検索）。分類できたら、[state-checklist.md](state-checklist.md)の中でも特に優先して確認すべき項目を示す。

## 一覧画面

優先確認: データの量（空・1件・大量件数）、通信エラー、権限差

- 空の時の案内文とアクション（例:「まだデータがありません。作成する」）
- 大量件数時のページネーション or 無限スクロールの挙動
- 並び替え・絞り込みがある場合、絞り込み結果が0件の時の表示

## 詳細画面

優先確認: 通信エラー、権限なし、極端値（長いテキスト）

- 対象データが削除済み・存在しない場合の表示
- 権限がない場合に詳細画面へ直接アクセスされた時の表示

## フォーム（作成・編集）

優先確認: 入力中、バリデーションエラー、送信中、送信成功/失敗

- 編集フォームの場合、初期値の表示
- 必須項目が未入力のまま送信しようとした時のエラー表示
- 送信中の多重送信防止（ボタンの非活性化など）
- 離脱時（未保存の変更がある場合）の確認ダイアログの要否をユーザーに確認する

## ダッシュボード・サマリー画面

優先確認: 読み込み中、データが一部欠損している場合

- 集計対象データが0件のカード/グラフの表示

## モーダル・ダイアログ

優先確認: 送信中、キャンセル操作

- 開いている間の背面操作の扱い（スクロール抑止など）
- 閉じる方法（×ボタン・オーバーレイクリック・Escキー）が画面骨子に無い場合は質問する

## 検索・フィルタ

優先確認: 検索結果0件、検索中

- 検索条件をクリアする操作の有無
