# state-checklist.md — 状態網羅チェックリスト

画面を作る際、指示がなくても以下を検討し、該当する状態は実装、該当しない状態は「検討して該当なしと明記」する。

## データの量

- [ ] 空（データが0件）
- [ ] 1件のみ
- [ ] 通常件数（複数件）
- [ ] 大量件数（ページネーション/スクロールの挙動）

## 通信・処理

- [ ] 読み込み中（ローディング）
- [ ] 通信エラー（取得失敗）
- [ ] 送信中（ボタン押下後の処理中表示）
- [ ] 送信成功
- [ ] 送信失敗（サーバーエラー）

## 入力・フォーム（フォームを含む画面のみ）

- [ ] 初期状態（未入力）
- [ ] 入力中
- [ ] バリデーションエラー（項目単位のエラー表示）
- [ ] 入力内容の保持（エラー後にやり直す際、入力済みの値が消えない）

## 権限・アクセス

- [ ] 権限あり（通常表示）
- [ ] 権限なし（機能非表示 or 権限エラー表示）
- [ ] ロール差（`admin` / `member` / `viewer` など、ロールによって表示が変わる場合）

## 極端値・エッジケース

- [ ] 文字数が極端に長い場合（テキスト折り返し・省略表示）
- [ ] 画像・アイコンが無い場合（代替表示）
- [ ] 同時に複数の操作が行われた場合（連打防止など）

## 判断に迷う場合

- 該当するかどうか不明な項目は、生成前の質問フェーズ（[SKILL.md](../SKILL.md) STEP1）でユーザーに確認する
- 「今回は対象外」と判断した項目は、完了報告に「検討して該当なし」として明記する（省略しない）
