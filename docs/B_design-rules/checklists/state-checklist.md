# 状態の網羅チェックリスト

画面を作るとき、指示がなくても以下を検討します。該当する状態は作り、該当しない状態は「該当なし」と明記します（省略しない）。

## データの量

- [ ] 空（0件）。空の理由と、次にすることを表示する
- [ ] 1件だけ
- [ ] 通常の件数
- [ ] 大量（ページ送り・スクロールの挙動）

## 通信・処理

- [ ] 読み込み中
- [ ] 取得の失敗（通信エラー）。再試行の手段がある
- [ ] 送信中（ボタンを押したあとの処理中の表示。連打できない）
- [ ] 送信の成功
- [ ] 送信の失敗（サーバーエラー）

## 入力（フォームのある画面）

- [ ] 初期状態（未入力）
- [ ] 入力中
- [ ] 項目ごとのエラー（該当欄の近くに、直し方を含めて）
- [ ] エラーのあとも、入力済みの値が消えない
- [ ] 送信前の確認（取り消せない操作の場合）

## 権限・役割

- [ ] 権限あり（通常の表示）
- [ ] 権限なし（機能を出さない、または権限がないことを表示）
- [ ] 役割による違い（例：`admin` / `member` / `viewer` で表示が変わる場合）

## 極端な値

- [ ] とても長い文字（折り返し・「…」で省略）
- [ ] 画像・アイコンがない場合の代わりの表示
- [ ] 大きな数値・桁の多い金額
- [ ] 同時に複数の操作をした場合（連打の防止など）

## 迷ったとき

- 該当するか分からない項目は、生成前の質問で依頼者に確認する
- 「今回は対象外」とした項目は、完了報告に「検討して該当なし」として書く
