# layout-patterns.md — レイアウトと画面テンプレート（枠組み）

値はトークン（`design-tokens.css`）を参照します。数値の後の「仮」は、導入先で決める値です。

## 1. グリッドと幅

| 項目 | 値 | トークン |
|---|---|---|
| 想定の画面幅 | PC 1366×768（仮）、最小幅 1024px（仮） | `--breakpoint-md` `--breakpoint-lg` |
| コンテンツの最大幅 | 1440px（仮） | `--layout-max-width` |
| サイドメニューの幅 | 240px（仮） | `--layout-sidebar-width` |
| ヘッダーの高さ | 56px（仮） | `--layout-header-height` |
| 列 | 12列、列の間 24px（仮） | `--space-6` |
| 画面の左右の余白 | 24〜32px | `--space-6` `--space-8` |

スマートフォンの画面がある場合：幅 375px を基準に、1列、左右 16px（`--space-4`）、押せる領域 44px 以上。

## 2. 余白の使い分け

| 関係 | 余白 |
|---|---|
| 部品の内側 | `--space-1`〜`--space-3` |
| 関連する要素の間（一覧の行、ラベルと入力） | `--space-1`〜`--space-2` |
| グループの間（カードどうし、フォームの区切り） | `--space-4`〜`--space-6` |
| セクションの間 | `--space-8`〜`--space-16` |

## 3. 画面テンプレート

すべてのテンプレートは「ヘッダー ＋（任意）サイドメニュー ＋ 本文」でできています。

### 3-1. 一覧

```
┌ header ─────────────────────────────────────────┐
│ nav │ 画面タイトル                       [主ボタン] │
│     │ 絞り込み（検索・セレクト）                    │
│     │ table（または card の一覧）                   │
│     │ ページ送り                                   │
└─────┴──────────────────────────────────────────┘
```
状態：空（`.empty`）・読み込み中・取得の失敗・大量件数。

### 3-2. 詳細

```
│ nav │ ← 戻る  タイトル        [編集] [その他]     │
│     │ 概要（ラベルと値の2列）                       │
│     │ 関連する一覧・履歴                            │
```
状態：読み込み中・見つからない・権限なし。

### 3-3. 入力（フォーム）

```
│ nav │ タイトル                                     │
│     │ field × n（1列。幅は最大 640px（仮））        │
│     │                       [キャンセル] [主ボタン] │
```
状態：未入力・入力中・項目のエラー・送信中・完了。取り消せない送信は確認の `.dialog` を挟む。

### 3-4. ダッシュボード

```
│ nav │ 期間の切り替え                               │
│     │ 数値の要約 3〜4個（同じ高さ）                 │
│     │ 主なグラフ（幅の2/3以上）│ 一覧・ランキング     │
```
状態：データなし・読み込み中・一部の取得失敗。

### 3-5. 設定

```
│ nav │ タブ（または左の小メニュー）                  │
│     │ グループごとの field（見出し＋説明＋入力）     │
│     │                                   [保存]     │
```
状態：未保存の変更あり（離れるときに確認）・保存の成功・失敗。

## 4. Figma での作り方（メモ）

- テンプレートは Figma のライブラリに「Templates」ページとして置き、部品はすべてインスタンスで組む。
- 画面名は `layer-naming-rules.md` の F-01 の形（`画面ID-画面名-画面状態-画面サイズ`）にする。
